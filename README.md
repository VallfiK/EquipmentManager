## 🚀 **Установка и запуск**

### 📦 **Зависимости**
Для работы программы необходимы следующие компоненты:
- **Python 3.8+**
- **Библиотеки**: `PyQt5`, `pandas`, `xlsxwriter`, `reportlab`, `sqlite3`

Установите зависимости с помощью команды:

```bash
# Установка зависимостей
pip install PyQt5 pandas xlsxwriter reportlab
```

### ⚙️ **Запуск программы**
Запустите программу с помощью команды:

```bash
python main.py
```

## 🛠️ **Основные функции**

### 1. **Добавление оборудования**
- Нажмите кнопку **"Добавить"** ➕.
- Заполните форму:
  - 📛 Наименование
  - 🗂️ Категория
  - 🔢 Серийный номер
  - 🟢 Статус (В работе/На ремонте/Списано).

> 📷 **Скриншот формы добавления**:  
> ![Форма добавления](https://github.com/user-attachments/assets/6c1f4881-6ea5-436d-8d4d-dc2967e6c4ee)

---

### 2. **Редактирование оборудования**
- Выберите оборудование в таблице.
- Нажмите **"Редактировать"** ✏️.
- Измените нужные поля и сохраните.

> ⚠️ **Важно!** Если возникает ошибка `_validate_update_data`, обновите код из репозитория.

---

### 3. **Генерация отчетов**
#### 📄 **PDF-отчет**
- Перейдите на вкладку **"Отчеты"** 📊.
- Нажмите **"Список оборудования (PDF)"**.
- Отчет сохранится в папке `reports/`.

> 📷 **Скриншот PDF-отчета**:  
> ![PDF-отчет](https://github.com/user-attachments/assets/0004d39d-8add-4777-b9b0-787a5acfbed1)

#### 📊 **Excel-отчет по ТО**
- Нажмите **"Оборудование с истекающим ТО (Excel)"** ⚠️.
- Файл сохранится в формате `.xlsx`.

## 🐛 **Решение частых проблем**

### 1. **Черные квадраты в PDF-отчетах**
- **Причина**: Отсутствие шрифта `DejaVuSans`.
- **Решение**: 
  1. Скачайте шрифт [отсюда](https://dejavu-fonts.github.io/).
  2. Поместите `DejaVuSans.ttf` в корневую папку проекта.

### 2. **Ошибка при сохранении цены**
- **Пример**: `ValueError: invalid literal for int() with base 10: '24000.0'`.
- **Решение**: Введите цену **без копеек** (например, `24000` вместо `24000.0`).
